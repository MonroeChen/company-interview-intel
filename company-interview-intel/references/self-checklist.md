# 出稿前自检

全部勾上才能交付。任一失败则修订后重检。

## 主体与结构

- [ ] 探查对象是用户确认的那家公司（同名已排除或已提问）
- [ ] 报告一级目录完整（一至九），没有把手册章节写进报告
- [ ] 岗位已知时，第六章对准该业务线，且无面试话术
- [ ] 岗位未知时未输出手册；或已询问岗位
- [ ] 手册 11 节完整；文首有岗位类型与对探查报告的引用

## 证据

- [ ] 关键数字都有口径
- [ ] 事实 / 推断 / 未核实可区分
- [ ] 冲突来源两说并存，未擅自裁定
- [ ] 客户/产品/嘉宾/展商名单未混源
- [ ] 没有编造营收、人数、刊例、毛利、股权
- [ ] 只看到标题的材料未当正文事实
- [ ] 第九章有分级表、删除或降级清单、仍未核实清单

## 身份视角

- [ ] 报告第七章是第一人称，含最高决策者 + 2～3 个真实角色
- [ ] 岗位已知时含对口上级或协作角色
- [ ] 手册未复制第七章独白
- [ ] 手册有「他在意 / 你该多聊 / 你该少聊」以及本岗位在飞轮中的位置

## 手册可用性

- [ ] 硬事实可背，推断已标记
- [ ] 有开场必问句、必问三题、必答三句、收尾三句、一页速记卡
- [ ] 有个人经历则第 6 节用其案例；无则标明替换
- [ ] 红旗结合该公司，不是纯万能条款
- [ ] 行为题场景匹配岗位类型

## 交付

- [ ] 文件名符合约定
- [ ] 对话摘要短，且不代替完整 Markdown
- [ ] 完整报告已写入工作区
